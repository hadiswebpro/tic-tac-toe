# 🎮 Tic Tac Toe

A responsive **Neon Glass Tic Tac Toe** game built with Vanilla JavaScript.

## 🌐 Live Preview

👉 **[Play Tic Tac Toe](https://hadiswebpro.github.io/tic-tac-toe/)**

Tic Tac Toe is also set up as an **installable Progressive Web App (PWA)** on supported browsers.

## ✨ Features

- 👥 Play against a friend
- 🤖 Play against a bot
- 🧠 Easy and Hard difficulty modes
- 🏆 Best-of-3 rounds
- 📱 Responsive mobile and tablet layout
- 💚 Neon-glass interface
- 📲 Installable as a standalone PWA
- 📴 Offline app-shell caching with a Service Worker
- 💾 Works from the installed app without needing the browser UI

## 📱 Install as an App

On a supported browser, open the live preview and use the browser's **Install / Add to Home Screen** option when it is available.

After installation, the game launches in a standalone app window instead of looking like a normal browser tab.

## 🚀 Run Locally

```bash
git clone https://github.com/hadiswebpro/tic-tac-toe.git
cd tic-tac-toe
```

Run the project through a local development server rather than opening `index.html` directly, because Service Workers require a secure origin such as HTTPS or localhost.
